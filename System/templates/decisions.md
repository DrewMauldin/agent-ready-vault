# Decisions log

One entry per decision or clarification question, in the owner's exact words where possible. The working log is System/decisions.md; this template shows its format. Agents read the log before asking questions (Rule 9): a decision recorded here is settled, and settled questions do not get asked again.

Copy the block below for each new entry. To change a decision, add a new entry and mark the old one superseded; never edit the old entry's wording. The one exception is the Status line of a clarification entry, which the agent updates in place as the loop moves (Rule 4 names this exception).
