# The clarification loop

This file is a short pointer. In this free lite repo, Rule 11 of `System/AGENT-RULES.md` states the principle: when a decision is genuinely yours, the agent asks instead of guessing, and your answer gets recorded as settled so the same question never reaches you twice.

The full guide in the paid package covers the working detail: the exact "[Clarify]" task format for Todoist (question, context, options, stable key), how you answer, how answers are applied on the next run, and a worked example from question to closed loop.

The full version of The Agent-Ready Vault is on Gumroad: https://mauldins.gumroad.com/l/llaegg

## If you are an agent reading this

The clarification loop is not set up in this lite vault, and the format it uses is not in this repo. Do not create tasks in any task app. When a decision belongs to the human, write the question in your run log under "Questions for the human", finish every part of the job that does not depend on the answer, and raise nothing anywhere else.
